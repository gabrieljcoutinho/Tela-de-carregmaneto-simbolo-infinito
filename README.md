# Infinity Outline Loader

Este projeto apresenta um loader animado baseado no símbolo do **infinito**, desenvolvido exclusivamente com **HTML**, **CSS** e **SVG**.

A animação utiliza técnicas avançadas de manipulação de traçados vetoriais, criando um efeito visual elegante e contínuo.

---

## ✨ Sobre o Loader

O loader é construído a partir de um único caminho SVG que representa o símbolo do infinito. A animação ocorre através da modificação dinâmica do traçado, produzindo a sensação de movimento fluido ao longo da curva.

O efeito transmite a ideia de continuidade, repetição e fluxo constante.

---

## 🎨 Conceito Visual

O design adota uma estética minimalista e moderna, explorando:

- Formas vetoriais suaves
- Movimento contínuo
- Animações de traçado
- Aparência limpa e elegante

O resultado é um loader sofisticado, ideal para interfaces modernas e projetos criativos.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando:

- HTML5 para estrutura
- CSS3 para animações
- SVG para o elemento gráfico
- Stroke animations (dasharray / dashoffset)
- Animações com `@keyframes`

---

## ⚡ Características

- Baseado inteiramente em SVG
- Animação suave e contínua
- Sem uso de JavaScript
- Visual minimalista
- Leve e performático
- Escalável para diferentes tamanhos

---

## 🎯 Objetivo do Projeto

Demonstrar como criar animações complexas e visualmente agradáveis utilizando apenas manipulação de traçados em SVG via CSS.

Este tipo de técnica é amplamente utilizado em loaders modernos e microinterações de interface.
